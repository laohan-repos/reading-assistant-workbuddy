# 读书助手

## 概述

把一本书读薄成一份可直接阅读的 Word 读书总结。输入一个书名（或留空由助手随机挑选一本经典），输出一份包含七大板块的结构化文档，自动命名为 `书名_作者_日期.docx` 并保存到当前工作区。

写作前**必须联网核实**书籍与作者的客观事实（出版时间、获奖、生平、创作背景等），避免凭记忆编造；正文用中文撰写，语气克制、可信、有洞察。

## 何时使用

- 用户给出书名并说「帮我总结」→ 直接进入流程。
- 用户说「随机一本书帮我总结」→ 由你从公认经典中挑选一本（中文读者熟悉、资料扎实者优先，如《活着》《平凡的世界》《百年孤独》等），并说明所选书目与理由。
- 用户自定义板块（如加「精彩摘录」「同类书推荐」「读后感问答」）→ 在七大板块基础上增删。

## 工作流程

```
1. 确定书目  →  2. 联网核实资料  →  3. 撰写七部分正文  →  4. 生成 Word 文档  →  5. 命名与交付
```

### 步骤 1 · 确定书目

确定书名与作者。若用户未指定，选一本经典并一句话说明理由。确认作者（用于文件命名）与作品的基本定位（体裁、国别、年代）。

### 步骤 2 · 联网核实资料（不可跳过）

用联网搜索核实以下客观事实，**至少检索 2 组关键词**（一个是「书名+作者+创作背景」，一个是「作者+生平简介+代表作」）：

- 出版时间、首发刊物/出版社、版本沿革、字数
- 作者生平：出生年份、籍贯、职业经历、创作转型、主要荣誉
- 创作背景：灵感来源、写作动机、时代语境
- 作品荣誉与影响力：获奖、销量、影视改编、翻译语种、文学史地位

把核实结果整理成研究快照（`research/<书名>_research.md`）留痕，事实不确定时宁可略写也不编造。

### 步骤 3 · 撰写七部分正文

按下方「内容规范」撰写七个板块，用标准 Markdown。总篇幅以 3500–5500 字为宜，信息密度高、不注水。正文中**不要**出现「根据搜索」「据网上资料」等字样，把事实直接写进叙述。

### 步骤 4 · 生成 Word 文档

**不要**用通用脚本或 python-docx 直接拼 Word。改为调用内置的 `tencent-docx` 技能，走专业文档流水线（创作 → 美化 → 转换），得到带封面页、目录、表格化信息的排版效果：

1. 调用 `Skill` 工具加载 `tencent-docx`，按其编排说明选择 **full_pipeline**（S1 创作 → S2 美化 → S3 转换）。
2. 把步骤 3 的 Markdown 正文作为 S2 排版的内容来源（若流水线要求 S1 重新创作，可直接把已写好的正文作为 S1 产出交付，避免重复劳动）。
3. S2 用 `general` 体裁（读书总结未命中垂类专家，走通用兜底），主题 `modern-minimal`。
4. S2 产出 HTML 须过 `html-review` 质量门禁；未过则定向修正一次（常见问题：margin/padding 用了裸数值而非 `var(--spacing-*)` 令牌；table 缺 thead）。
5. S3 将 HTML 转为 `.docx`，输出路径用步骤 5 的目标文件名。

> 若 `tencent-docx` 技能当前不可用，降级：用标准 Markdown 直接生成，并通过其它可用方式导出为 `.docx`，末尾说明降级原因。

### 步骤 5 · 命名与交付

- 文件名：`书名_作者_日期.docx`（例：`活着_余华_2026-10-12.docx`），日期取运行当天。
- 保存位置：**当前工作区根目录**（用户的项目目录），不要埋进多层子目录。
- 用 `present_files` 把最终 `.docx` 呈现给用户。
- 中间产物（研究快照、正文 md、HTML、溯源文件）可保留在 `output/<请求ID>/` 下，便于追溯与二次修改。

## 内容规范（七大板块）

每个板块的写作要点见 `references/content-template.md`，务必遵循。七部分依次为：

1. **书籍基本信息** —— 书名、作者、体裁、首版时间、字数、主要版本、荣誉、影视/翻译情况。
2. **作者介绍** —— 生平脉络、出身与职业经历、文学地位、代表作、风格演变、国际评价。
3. **创作背景** —— 灵感来源、写作动机与心境、时代语境、作品在其创作序列中的位置。
4. **故事概括** —— 主要人物与人物关系、情节主线分阶段推进、结局，做到脉络清晰而非流水账。
5. **内容总结** —— 主题思想、核心意象与母题、叙事手法（视角、结构、节奏）、情感基调。
6. **章节分析** —— 按结构阶段或关键章节做剖析；可用表格呈现「阶段—核心事件—人物处境—写作意图」；点出结构设计（如重复母题、象征、伏笔）。
7. **阅读思考** —— 就生命/人性/时代/性别等维度提出 3–5 点有深度的思辨，避免空泛鸡汤，最后可留一个开放性问题。

## 写作风格

- 中文为主，术语准确；引用原文时用引号并核对是否确为该作内容。
- 克制、可信、有观点，避免营销式夸张与网络口水话。
- 客观事实优先，主观解读要有文本或史料支撑。
- 表格、列表适度使用，让信息更易扫读。

## 输出检查清单

交付前自查：

- [ ] 七大板块齐全，标题清晰。
- [ ] 客观事实已联网核实（出版时间、作者生平、创作背景等）。
- [ ] 文件名符合「书名_作者_日期.docx」，日期为当天。
- [ ] 文件保存在当前工作区根目录。
- [ ] 已用 `present_files` 呈现，并附一段简短说明（书目、篇幅、板块亮点）。
