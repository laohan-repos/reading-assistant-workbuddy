# 读书助手（Reading Assistant）

把一本书记薄成一份可直接阅读的 **Word 读书总结**。给出一个书名（或让助手随机挑一本经典），即可自动产出一份包含 **封面页、目录、七大板块** 的结构化文档，并命名为 `书名_作者_日期.docx` 保存在工作区。

本项目同时是一个 **WorkBuddy Agent Skill** 的完整示例：把「联网核实 → 撰写 → 排版 → 导出 Word」的全流程封装成可复用的能力。

---

## ✨ 功能特性

- **七大固定板块**：书籍基本信息 / 作者介绍 / 创作背景 / 故事概括 / 内容总结 / 章节分析 / 阅读思考
- **事实为先**：写作前联网核实出版信息、作者生平、创作背景等客观事实，杜绝编造
- **专业排版**：调用内置文档流水线，生成带封面页、目录、表格化信息的成品 Word（A4）
- **规范命名**：`书名_作者_日期.docx`，直接落盘到工作区根目录
- **触发灵活**：指定书名、随机选书、自定义增删板块皆可

---

## 🚀 使用方式

用自然语言一句话即可触发：

```
帮我总结《围城》
随机一本书帮我总结
用读书助手总结《百年孤独》，加上「精彩摘录」板块
```

触发词：`读书总结`、`书籍总结`、`读书笔记`、`书评`、`读书报告`、`读后感`、`随机一本书帮我总结` 等。

---

## 🧭 工作流程

```
① 确定书目 → ② 联网核实资料 → ③ 撰写七部分正文 → ④ 生成 Word 文档 → ⑤ 命名与交付
```

1. **确定书目**：用户给出书名；或由助手从公认经典中挑选并说明理由。
2. **联网核实**：检索并核实出版时间、作者生平、创作背景、获奖改编等硬事实。
3. **撰写正文**：按七大板块撰写标准 Markdown，篇幅 3500–5500 字，信息密度高、不注水。
4. **生成 Word**：复用内置 `tencent-docx` 文档流水线（创作 → 美化 → 转换），产物经质量门禁校验。
5. **命名交付**：输出 `书名_作者_日期.docx`。

## 🛠 技术说明

文档生成复用 WorkBuddy 内置的 `tencent-docx` 流水线（`general` 体裁 + `modern-minimal` 主题），HTML 版式须通过 `html-review` 质量门禁后转换为 `.docx`。

**质量门禁要点（踩坑备忘）**

- CSS 中所有 `margin` / `padding` 必须使用间距令牌 `var(--spacing-*)`，不可用裸值。
- 每个 `<table>` 必须同时包含 `<thead>`（含 `<th>`）与 `<tbody>`。
